# Runtime dependencies for the deployed image (EMBED_BACKEND=onnx).
#
# requirements.txt stays the full dev set: it is what builds the FAISS index and
# what `EMBED_BACKEND=torch` needs. Installing it in the image pulls
# sentence-transformers -> torch, and the Linux torch wheel drags in ~2 GB of
# CUDA libraries that the service never imports, which turns a free-tier Docker
# build into a multi-gigabyte image for no benefit.
#
# Nothing under main -> agents/* imports torch, transformers or
# sentence-transformers at module level; the torch encoder and the cross-encoder
# reranker are imported lazily and are both opt-in.
